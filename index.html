Parte 1 · Seções 5.2 e 5.3

Os gráficos de seno e cosseno

Tudo sai do círculo trigonométrico: o seno é a coordenada y, o cosseno é a coordenada x.

5.2 · O círculo trigonométrico

Cada número real θ vira um ponto do círculo

  • Círculo de raio 1, centro na origem
  • Arco de comprimento |θ| a partir de (1, 0)
  • anti-horário se θ ≥ 0, horário se θ < 0; pode dar várias voltas
  • Ponto final: (cos θ, sen θ)
Exemplos da apostila:
Apostila, p. 129–130
Do círculo ao gráfico

O seno é a altura do ponto

━ comprimento do arco θ vira a abscissa  ·  ┃ altura sen θ vira a ordenada
Do círculo ao gráfico

Seno = coordenada y · Cosseno = coordenada x

Apostila, p. 131
5.2 · Fatos imediatos da definição

Domínio, imagem e a relação fundamental

sen : ℝ → ℝ     cos : ℝ → ℝ
Imagem de ambas: [−1, 1]
cos2θ + sen2θ = 1
(o círculo é x2 + y2 = 1)
Apostila, p. 130–131
5.2 · Periodicidade

Período 2π: o gráfico se repete a cada volta

sen(θ + 2kπ) = sen θ,   cos(θ + 2kπ) = cos θ,   k ∈ ℤ
Basta conhecer o gráfico em um intervalo de comprimento 2π: o resto são cópias.
Apostila, p. 131
Lendo o gráfico

Seno e cosseno: o mesmo gráfico, deslocado

cos x = sen(x + π/2)

━ y = sen(x + c): o gráfico do seno deslocado c para a esquerda.
┅ y = cos x: coincide quando c = π/2.
Por quê?  sen(x + π/2) = sen(π − (x + π/2)) = sen(π/2 − x) = cos x  (Seção 5.4)

Cinza: y = sen x (referência)

Ângulos “comuns” e paridade

Com um triângulo adequado, calculamos sen e cos exatamente. Simetrias do círculo fazem o resto.

5.4 · π/3 e π/6

O triângulo equilátero de lado 1

1Ângulos internos iguais a π/3
2A altura encontra o lado oposto no ponto médio
3Pitágoras: h2 + (1/2)2 = 1 ⇒ h = √32
sen(π/3) = cos(π/6) = √32
cos(π/3) = sen(π/6) = 12
tg(π/3) = √3,   tg(π/6) = 1√3 = √33

1Quadrado de lado 1
2A diagonal forma um triângulo com catetos 1 e ângulos π/4

sen(π/4) = cos(π/4) = 1√2 = √22

5.4 · Simetria em relação à reta y = x

Ângulos complementares: θ e π/2 − θ

sen(π/2 − x) = cos x
cos(π/2 − x) = sen x
Refletir na reta y = x troca as coordenadas.
Apostila, p. 135–136
5.4 · Simetria em relação ao eixo y

Ângulos suplementares: θ e π − θ

sen(π − x) = sen x
cos(π − x) = −cos x
Mesmo seno (mesma altura), cossenos opostos.
Apostila, p. 136
5.4 · Simetria em relação ao eixo x

Paridade: cos é par, sen é ímpar

cos(−θ) = cos θ    sen(−θ) = −sen θ
Apostila, p. 136–137

Parte 3 · Seção 5.5

Fórmulas de adição de arcos, e ainda outras fórmulas

Como calcular sen(α + β) a partir de sen e cos de α e de β?

Antes de tudo: um erro comum

sen(a + b) ≠ sen a + sen b

Ex.: a = b = π/2:   sen π = 0,  mas  sen π/2 + sen π/2 = 2
5.5 · A fórmula do seno da soma, em uma figura

A altura de P é a soma de duas alturas

0Hipotenusa 1, ângulo α + β: altura = sen(α + β)
1Ângulo β: catetos cos β e sen β
2Embaixo: ângulo α, hipotenusa cos β
→ altura sen α · cos β
3Em cima: ângulo α, hipotenusa sen β
→ altura cos α · sen β
sen(α + β) =
sen α cos β + cos α sen β
Bônus (na horizontal): cos(α + β) = cos α cos β − sen α sen β
ideia da apostila, p. 138
5.5 · Teorema 5.1 (Fórmulas de adição de arcos)

As outras três saem da primeira

sen(α + β) = sen α cos β + sen β cos α a figura
sen(α − β) = sen α cos β − sen β cos α troque β por −β
cos(α + β) = cos α cos β − sen α sen β use cos x = sen(π/2 − x)
cos(α − β) = cos α cos β + sen α sen β troque β por −β
Lembre: cos(−β) = cos β e sen(−β) = −sen β (paridade).
tg(α + β) = tg α + tg β1 − tg α tg β tg(α − β) = tg α − tg β1 + tg α tg β (dividindo sen por cos)
Apostila, p. 138–139
5.5 · Fórmulas de arco duplo (α = β = x)

sen(2x) e cos(2x)

sen(2x) = 2 sen x cos x      cos(2x) = cos2x − sen2x = 2 cos2x − 1 = 1 − 2 sen2x
Note: sen 2x e cos 2x têm período π.
Apostila, p. 140
5.5 · Produtos ↔ somas

Somando e subtraindo as fórmulas de adição

sen a cos b = ½(sen(a + b) + sen(a − b))
cos a cos b = ½(cos(a + b) + cos(a − b))
sen a sen b = ½(cos(a − b) − cos(a + b))
Com x = a + b, y = a − b:
sen x + sen y = 2 senx + y2cosx − y2
e analogamente para sen x − sen y, cos x + cos y, cos x − cos y.
Aplicação: batimento — sen(pt) + sen(qt) com envelope ±2 cos((p − q)t2)
Apostila, p. 140–141
Exemplo da apostila (Seção 5.7) · usando arco duplo

Resolver sen(2x) − cos(x) = 0

12 sen x cos x − cos x = 0
2cos x (2 sen x − 1) = 0
3cos x = 0  ou  sen x = 1/2
x = π/2 + kπ
ou x = π/6 + 2kπ
ou x = 5π/6 + 2kπ,  k ∈ ℤ
Apostila, p. 145–146

Parte 4 · Seção 5.3

A função tangente

Definição no triângulo e no círculo, domínio, sinais por quadrante, período π e valores notáveis.

5.3 · Definição da tangente

Tangente: cateto oposto sobre cateto adjacente

tg θ = cateto opostocateto adjacente = ba
Dividindo em cima e embaixo pela hipotenusa c:
tg θ = ba = b/ca/c = sen θcos θ
Definição geral (qualquer x real):
tg x = sen xcos x  sempre que cos x ≠ 0
Domínio: cos x = 0 ⇔ x = π/2 + kπ, logo
D(tg) = ℝ − {π/2 + kπ | k ∈ ℤ}
Apostila, p. 133
5.3 · A tangente no círculo trigonométrico

tg θ é a altura do ponto T na reta x = 1

  • Reta tangente ao círculo em (1, 0): x = 1
  • A reta OP corta x = 1 em T = (1, tg θ)
  • Sinal: + no 1º e 3º quadrantes, − no 2º e 4º
Apostila, p. 133–134
5.3 · Relação com seno e cosseno

tg θ = sen θ / cos θ: triângulos semelhantes

tg θ1 = sen θcos θ  ⇒  tg θ = sen θcos θ
Mesmo ângulo θ e ângulo reto ⇒ triângulos semelhantes (lados proporcionais).
Não definida quando cos θ = 0:
D(tg) = ℝ − {π/2 + kπ | k ∈ ℤ}
Apostila, p. 133
5.3 · Sinais e período da tangente

Sinal de tg = sinal de sen ÷ sinal de cos

quadrantesencostg = sen/cos
1º+++
2º+−−
3º−−+
4º−+−
Período π. θ e θ + π são pontos diametralmente opostos:
sen(θ + π) = −sen θ,  cos(θ + π) = −cos θ
⇒ tg(θ + π) = tg θ  (a mesma reta corta x = 1 no mesmo T)
Apostila, p. 134
5.4 · Valores notáveis da tangente

tg(π/6), tg(π/4), tg(π/3)

Também: tg 0 = tg π = 0, e tg(π/2) não existe (cos(π/2) = 0).
No meio quadrado, os catetos são iguais: tg(π/4) = 1.
Clique numa linha. Quanto mais perto de π/2, mais alto fica T.
Apostila, p. 135, 137

Secante, cossecante e cotangente

As três funções “coadjuvantes”: definições, domínios, duas identidades, a leitura no círculo e um exemplo completo.

5.6 · Definições

Três funções definidas a partir de sen e cos

funçãodefiniçãodomínioimagemperíodoparidade
tg xsen xcos xℝ − {π/2 + kπ}ℝπímpar
sec x1cos xℝ − {π/2 + kπ}(−∞, −1] ∪ [1, ∞)2πpar
cossec x1sen xℝ − {kπ}(−∞, −1] ∪ [1, ∞)2πímpar

Por que esses domínios? Não se divide por zero:
tg e sec precisam de cos x ≠ 0; cossec e cotg precisam de sen x ≠ 0.  (k ∈ ℤ)
Cuidado: sec x = 1/cos x é o inverso multiplicativo de cos x. Não é a função inversa arccos (Seção 5.8).
Apostila, p. 141
5.6 · Secante, cossecante e cotangente

Três novas funções, vistas no círculo

sec x = 1cos x   cossec x = 1sen x   cotg x = cos xsen x
Apostila, p. 141–143
5.6 · Cotangente e duas identidades

cotg tem período π · e duas identidades úteis

tg2x + 1 = sec2x
cotg2x + 1 = cossec2x
Basta dividir sen2x + cos2x = 1 por cos2x ou por sen2x.
D(cotg) = ℝ − {kπ | k ∈ ℤ}
Imagem: ℝ  ·  Período: π
Períodos: sec 2π, cossec 2π, cotg π.
Apostila, p. 141–142
5.6 · Exemplo

tg x = 3/4 e π < x < 3π/2. Ache as outras cinco.

1sec2x = 1 + tg2x = 1 + 916 = 2516 ⇒ sec x = ±54.
No 3º quadrante, cos x < 0, então sec x = −5/4.
2cos x = 1sec x = −45
3sen x = tg x · cos x = 34 · −45 = −35
4cossec x = −53,  cotg x = 1tg x = 43
Conferindo: sen2x + cos2x = 925 + 1625 = 1 ✓
Apostila, p. 141
